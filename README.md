# 🌱 PlantDoc AI Agent

An AI-powered **Plant Disease Detection and Assistance Agent** designed to help identify plant diseases from leaf images and provide useful information to users.

The system combines **Computer Vision, Machine Learning, and an AI Agent** to analyze plant images and generate intelligent plant-care assistance.

## 📌 Project Overview

Plant diseases can significantly affect crop health and agricultural productivity. Early identification of diseases can help farmers and plant owners take appropriate action.

**PlantDoc AI Agent** allows users to upload an image of a plant leaf. The system analyzes the image using an AI-based image classification model and predicts the possible disease.

The detected result can then be used by the AI Agent to provide relevant information and guidance.

4. Disease classification
